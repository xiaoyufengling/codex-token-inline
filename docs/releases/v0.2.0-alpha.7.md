## 简体中文

修复回复末尾有文件卡片时，卡片文字遮住 Token 悬停明细的问题。明细改为顶层浮窗，保持原有简洁外观；靠近窗口边缘会调整位置，支持键盘聚焦、Esc 关闭，滚动时自动收起。

本段 / 总量、绿色 / 灰色、输入 → 输出 → 缓存命中的顺序与统计逻辑保持不变。仍仅支持 Codex 工作模式；普通 ChatGPT 聊天模式暂未支持。

下载下方安装包，正常退出 Codex 后覆盖安装，再通过 Codex Token Inline 增强入口启动原版。更新可选，不强制更新。

## English

Fix attachment cards painting over token usage details. The tooltip now uses the browser top layer, preserves the compact appearance, stays inside the viewport, supports keyboard focus and Escape, and closes on scroll.

Segment / total accounting, active / completed colors, and Input → Output → Cache hits remain unchanged. Codex work mode only; regular ChatGPT chat remains unsupported.

Download the installer below, quit Codex normally before upgrading, then use the Codex Token Inline enhanced entry to launch the original client. Updates remain optional.

## Verification / 开源

Browser regression reproduced the old attachment overlap and verified the fix, plain text endings, native overflow clipping, viewport bounds, and keyboard dismissal. Full local tests passed. This does not claim full uninstall testing for this release.
