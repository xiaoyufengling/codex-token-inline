# 安装与版本管理：已确认方向

当前状态：alpha.4 提供原版窗口接入的 Windows 安装器、中英文管理和用量界面、卸载入口。以下更新与版本选择部分是后续方向，尚未实现。

## 安装与品牌

- GitHub 下载一个 Windows 安装程序，双击即可检查兼容性并安装，无需开发工具。
- 使用 assets/branding/icon-source.png 作为图标原稿，按透明内容边界适配并导出多尺寸 ICO；安装器和启动器已使用该图标。
- 安装器与管理页显示版本、作者 xiaoyufengling 及 GitHub 链接。仓库为 https://github.com/xiaoyufengling/codex-token-inline。
- 安装后按实际情况提示下次启动生效，提供可选重启，不中断正在执行的任务。
- 日常无额外窗口或托盘，沿用简单的内嵌数字。

## 更新与版本选择

- 启动时异步检查更新，不阻塞 Codex 启动；网络失败不影响使用。
- 同一天重复启动优先用缓存，避免反复请求和重复提示。
- 有适用的新版本时提供更新、稍后、跳过此版本；不强制升级。
- 管理页提供版本列表、发行说明、Codex 兼容性与手动检查。默认稳定版，预览版由用户主动选择。
- 允许安装与当前 Codex 兼容的历史版本；不静默替换用户选择。
- 安装前校验发布包及兼容性；失败保留可用版本。版本切换涉及配置格式时必须保留恢复路径。
- 发布来源应配置化，便于 fork 作者替换自己的仓库；不把私有凭据放入客户端。

## 卸载与可维护性

- Windows 已安装应用和安装管理页均可卸载。
- 以安装清单追踪自有文件、缓存、设置、快捷方式和修改的入口。卸载清理自身内容、恢复入口，不删除原版 Codex、聊天或账号资料。
- 文件占用时提示关闭后继续，清理成功后才报告完成。
- 品牌资源、版本来源、兼容适配、统计核心与界面保持独立，便于更换图标、样式和发行源。
- 当前安装器不包含 Codex 客户端或私人数据；体积主要来自附带的 Node 运行环境。
- Windows 安装及卸载路径已有前版实机验证；alpha.4 完整复测与跨设备验证仍待补充。启动更新检查和内置版本选择尚未实现。
