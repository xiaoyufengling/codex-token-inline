# 安装、更新与维护

alpha.6 提供原版窗口接入的 Windows 安装器、中英文管理页、启动更新检查和卸载入口。日常不额外常驻托盘；启动检查完成后退出。

- 更新检查：每日一次，Codex 版本变化时重查，管理页可手动检查。
- 更新选择：下载并安装、稍后、跳过此版本；不强制升级，不自动关闭 Codex。
- 兼容匹配：发行版附带 compatibility.json；Windows structural-v1 声明允许跨版本发现更新，实际接入仍须通过本机结构识别和逐消息记录核对。保留已知版本列表用于旧更新器。
- 文件验证：下载兼容清单与安装包后校验 GitHub 提供的 SHA-256。
- 安装升级：识别本项目安装后可以覆盖更新；保留语言，增强运行时要求先退出。
- 版本选择：管理页链接到 GitHub 所有版本。用户可主动选择兼容版本；尚无内嵌历史版本列表或自动回滚。
- 卸载：按安装清单删除自有文件及明确列出的偏好、更新状态和下载包；不清理 Codex 数据。
- 品牌：透明图标适配至内容边界，安装器显示版本、作者与 GitHub 链接。

完整协议与发布步骤见 [更新机制](updates.md)。本机覆盖安装与兼容性检查已验证；当前原版窗口的结构匹配和用量显示已验证；正常冷启动及本版更新状态的完整卸载复测仍待补充。旧版验证不代表所有设备都兼容。
