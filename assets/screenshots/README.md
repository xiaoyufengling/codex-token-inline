# Screenshot provenance

These PNGs preserve real pixels from screenshots supplied by the project owner on September 8, 2026. They show the counter in the original Windows Codex client. No values, colors, or text were redrawn or generated.

- `active-single.png`: cropped to the first green counter.
- `active-total.png`: cropped to a green segment/total counter.
- `complete-total.png`: the owner's tightly cropped gray counter, preserved in full.

Every public image was visually inspected. Only counter text and its background remain. These independent examples are not a continuous accounting sequence. The full source screenshots are private and are not distributed.
